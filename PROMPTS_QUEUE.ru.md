# Очередь промптов для последовательных чатов Kimi (agent-forge)

Каждый промпт — для ОТДЕЛЬНОГО нового чата Kimi в папке `D:\study\fantasy\agent-forge`.
Чаты не видят контекст друг друга — каждый промпт самодостаточен.
Порядок важен: треки A (документация) и B (UI) независимы, внутри трека — строго по номерам.

Общие правила, заложенные в каждый промпт:
- НЕ запускать живые LLM-прогоны (forge run/wizard с реальным API) — токены DeepSeek
  исчерпаны. Только mock-режим (FORGE_MOCK=1) и детерминированные команды.
- Проверки перед коммитом: `pytest -q`, `ruff check forge tests`, `mypy forge`;
  для сайта: `python site/build_pages.py`.
- Документация — двуязычная (ru + en).
- Коммит в master и push: `git push https://github.com/Xarawg/agent-forge.git master`.

## Правила запуска

1. Чаты идут строго по номерам внутри трека; A и B можно вести параллельно;
   C1 — только после завершения обоих треков.
2. После A1 и после B2 чат остановится и будет ждать вашего «да» — это гейты.
3. Если чат упрётся в лимит контекста — откройте новый чат с тем же промптом
   и строкой «Продолжи с места остановки; состояние смотри в git log и файлах».
4. Финал каждого чата — зелёные проверки и push. Этот файл в репозиторий не
   коммитить.
