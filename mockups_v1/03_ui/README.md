# Стадия 3 — UI-мокапы

Два самодостаточных HTML-файла (офлайн, ноль CDN, открываются двойным кликом):

- **`ux-board.html`** — lo-fi wireframes: композиция всех экранов и состояний
  без стилистики (серые блоки, подписи, аннотации). Проверяем информационную
  архитектуру и приоритеты.
- **`ui-board.html`** — hi-fi мокапы поверх wireframes: токены `site/`
  (Q-03), демо-данные прогона, рабочие переключатели экранов и RU/EN,
  кликабельные карточки → drawer событий, copy-кнопки. Это эталон, по
  которому пишется продакшн-`index.html`.

## Визуальное направление

Скилл предписывает musepool plugin для visual direction. Плагин в этом
окружении **недоступен** (нет в индексе скиллов), но направление и не
требовалось выдумывать: оно зафиксировано директивой владельца («тёмная тема
в духе site/») и решением Q-03 (токены site/, без декора лендинга). Мокапы
выведены из `site/index.html` + `../02_ux/ux-spec.md`, не из воображения.
