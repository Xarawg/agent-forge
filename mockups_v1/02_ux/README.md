# Стадия 2 — UX до release-уровня

Основной артефакт: `ux-spec.md` — полная UX-спецификация редизайна веб-UI
agent-forge (v1), построенная по одобренным решениям Q-01…Q-09
(`../01_spec_audit/PROPOSED_DECISIONS.md`, гейт пройден 2026-08-26,
«принято всё»).

Покрытие: все экраны из `../coverage-map.md` (канбан, отчёт, панель событий,
wizard-форма, кросс-экранные состояния), все состояния и краевые случаи:
пустые данные, битые файлы, потеря соединения, узкий экран, переключение
языка. Каждый экран описан до уровня, достаточного для мокапа и последующей
реализации: данные (с контрактом API), состояния, действия, строки i18n.

Контрактные изменения API (read-only) собраны в `ux-spec.md` §3 — это
единственное место, где v1 требует правок сервера (`forge/ui.py`), и они не
затрагивают `runs/` на запись.
