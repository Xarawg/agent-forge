# Шаблон AGENTS.md для целевого репозитория (копируется в монорепо продукта)

Этот файл ложится в корень продуктового монорепозитория «Атлас» и задаёт правила
всем AI-агентам, работающим в нём (agent-forge, сессии Kimi Code владельца).

## Источники истины

- Машиночитаемый канон: `canon/` (модули, события, defs, мир) — правится только
  оркестраторской волной, из кодогенерации — read-only.
- Реестр решений: `canon/decisions.json` (генерируемый) / `docs/design/DECISIONS.md`.
- Канон для людей: последняя `docs/design/DESIGN_SYSTEM_v*.md`.
- Как работать со спецификациями: `SPEC_GUIDE.md` (корень).

## Обязательные проверки перед коммитом

1. `python tools/validate_canon.py` — 0 ошибок (если diff трогает canon/ или events).
2. Тесты изменённых пакетов — зелёные.
3. Lint/typecheck по стандарту репозитория.

## Запреты

- Не выдумывать геймплейные числа: только canon (config модулей / defs).
- Не вводить события/модули вне реестра canon/ (нужно новое — GAP оркестратору).
- Не хардкодить секреты; конфиги через env.
- Не править генерируемые файлы (MANIFEST.md, canon/decisions.json, INDEX.md ассетов).

## Язык

Документация и комментарии — русский; код, идентификаторы, коммит-сообщения — английский.
